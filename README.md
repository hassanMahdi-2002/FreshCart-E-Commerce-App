### 📌 Overview & Purpose

**FreshCart** is a modern e-commerce web application engineered with **React.js** and **Bootstrap 5**. It integrates with RESTful APIs to handle core digital retail workflows, including secure JWT user authentication, dynamic product/brand filtering, state-driven cart operations, and checkout processing.

### ✨ Key Features

    <td style="padding: 20px; border: none; color: #c9d1d9; line-height: 1.8;">
      <p style="margin: 0 0 12px 0;">🔐 <b>Authentication & Security:</b> Secure User Registration and Login forms powered by <b>Formik</b> validation and <b>JWT Decode</b> for token verification.</p>
      <p style="margin: 0 0 12px 0;">🛍️ <b>Catalog & Product Details:</b> Comprehensive product listings with dynamic routing to granular item detail views.</p>
      <p style="margin: 0 0 12px 0;">🏷️ <b>Brand Exploration:</b> Interactive brand browsing with dynamic, brand-based product filtering.</p>
      <p style="margin: 0 0 12px 0;">🛒 <b>Cart Management:</b> Full shopping cart lifecycle powered by <b>Context API</b>, allowing real-time quantity updates and item removals.</p>
      <p style="margin: 0 0 12px 0;">💳 <b>Flexible Checkout:</b> Multi-option checkout workflow supporting shipping details, Cash on Delivery (COD), and online payment processing.</p>
      <p style="margin: 0;">👤 <b>Profile & Orders:</b> Personalized User Profile management alongside historical order tracking.</p>

# 2. Navigate into the directory

# 3. Install dependencies
npm install

# 4. Start the development server
