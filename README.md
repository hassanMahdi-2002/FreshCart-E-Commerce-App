### 📌 Overview & Project Purpose

This project is a modern, full-fledged **E-Commerce Application** designed to simulate real-world digital retail platforms. It bridges intuitive front-end user experience with resilient back-end API integrations, handling everything from authentication and dynamic catalog navigation to cart operations and order processing.

### ✨ Key Features & Technical Details

<table width="100%" style="background-color: #0d1117; border: 1px solid #30363d; border-radius: 8px;">
  <tr>
    <td style="padding: 20px; border: none; color: #c9d1d9; line-height: 1.8;">
      <p style="margin: 0 0 12px 0;">🔐 <b>Secure User Authentication:</b> Token-based JWT authentication for User Registration, Login, and Password Reset with client-side form validation.</p>
      <p style="margin: 0 0 12px 0;">🛍️ <b>Dynamic Product Catalog:</b> Paginated product listings, real-time filtering by categories/brands, and live search functionality.</p>
      <p style="margin: 0 0 12px 0;">🔍 <b>Detailed Product Views:</b> Interactive image galleries, stock status indicators, pricing calculations, and customer review sections.</p>
      <p style="margin: 0 0 12px 0;">🛒 <b>Advanced Shopping Cart:</b> Persistent state management allowing real-time quantity adjustments, price recalculations, and item removals.</p>
      <p style="margin: 0 0 12px 0;">❤️ <b>Wishlist Management:</b> Toggle items in/out of custom user wishlists with instant feedback indicators.</p>
      <p style="margin: 0 0 12px 0;">💳 <b>Checkout Integration & Orders:</b> Multi-step checkout pipeline supporting Cash on Delivery and online payment gateways.</p>
